# Implementation specification

Follow [ROADMAP.md](ROADMAP.md) for implementation order and completion gates.
The latest city-zone policy is [WORLD-GENERATION.md](docs/WORLD-GENERATION.md), with the complete [rule register](docs/GAME-RULES.md).

The current English specification is [IMPLEMENTATION-PLAN.md](IMPLEMENTATION-PLAN.md).

It supersedes the preparation-stage design: shared street coins have real GOLD denomination in the intended native economy, a 50/50 yield split funds coins and zones, and solo play is the primary loop. The current deployed release explicitly uses a separate demo ledger.

The accepted next-phase extension is [CREATOR-ECONOMY-PLAN.md](CREATOR-ECONOMY-PLAN.md): Community navigation, refundable XP commitments excluded from current level, configurable creator funding, follows/support, donations and paid quest access split 80% creator / 20% treasury. It allocates only future eligible income and preserves existing reward backing; it is a plan, not implemented behavior.
