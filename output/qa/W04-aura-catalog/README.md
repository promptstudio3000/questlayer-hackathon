# W04 Aura catalog v2 — rendered sprite sheet

`aura-sheet.png` shows every catalog edition (rows, catalog order: ember, dew, polar, bloom, storm, moon, comet, gold, nova) in the `above` and `below` slots. The left half shows sparkle frame `a`, the right half frame `b`, at 5x scale on the paper background. Rendered with `render-sheet.mjs` (sharp rasterizing `auraMarkup`). Source: `src/aura-art-data.ts`.

`wardrobe-phone390.png`, `wardrobe-phone360.png` and `wardrobe-desktop.png` are full-page captures of `dev/inventory.html` (fixture with six catalog Auras, Night Sky set equipped, catalog opened) in headless Chromium. Browser layout evidence only, not physical-device verification.
