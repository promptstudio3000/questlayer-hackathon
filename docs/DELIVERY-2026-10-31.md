# AuraTrail delivery — 31 October 2026

Public preview: **https://questlayer.promptstudio3000.com/**.

This is a playable English-language demonstration with separately verified native NEAR testnet contracts. Demo GOLD has no monetary value. Gameplay does not deposit a connected wallet's real funds.

## Delivered

- Real OpenStreetMap geography, a styled MapLibre map, globe view, a following camera and an original explorer character.
- A shared Pilsen demonstration arena plus GPS-generated local worlds from cached public pedestrian routes. Physical GPS remains a trusted and spoofable input.
- Daily world replacement at local midnight, DST-aware expiry, six initial zones, automatic nearby shared coins and solo quests.
- Separate conserved coin and zone budgets, 50/50 incoming game contributions, backed publication and rollover of unclaimed rewards.
- Persistent demo inventory, above/below Aura effects, equipment and an atomic peer market.
- Model staking pools, 0–100% contribution selection, weighted tiers, contribution changes, retained model yield and queued withdrawals. Arena timing is explicitly accelerated.
- Verified WebAuthn registration and account recovery for demo identity; no player private key or seed is stored.
- Native NEAR wallet ownership verification through NEP-413 and actual testnet balance reads.
- EVM address verification and read-only canonical Aavegotchi ownership, appearance and wearable inventory on Base. Original assets remain on Base and cannot be sold through the demo market.
- Public map notes, optional author GPS, sanitized image attachments, optional 15-minute presence and demonstration task escrow.
- An optional NEAR AI guide with an identified rules-based fallback.
- Rust game accounting and NEP-171 collectible contracts, deployed and exercised on NEAR testnet.

## Deployment and ownership

The application has its own loopback service, release directories and SQLite state. Deployment backs up routing and existing SQLite data, verifies service health, then validates and reloads the requested domain route. A failed activation restores the previous release and routing.

No player keys or developer operator keys are uploaded with the application release. The ignored local operator key controls dedicated development accounts only. The public manifest contains account addresses and transaction hashes, never signing secrets.

The exact active release and backup directories are recorded in `output/qa/deployment-status.json`. That operational snapshot contains no credentials or player sessions.

## Remaining delivery gates

The staking vault, actual realized-yield harvesting, native passkey accounts, native player profiles/avatar minting, gameplay-to-contract settlement, native marketplace/Intents, SocialDB and IPFS publishing are **not connected to gameplay**. A connected wallet does not turn demo GOLD into NEAR.

The current six demonstration zones are open throughout their daily instance. Varied opening schedules, richer quest templates, regional activation quotas and robust physical-proof review remain subsequent work. The current character is a 2D SVG on a 3D map; the original Aavegotchi GLB wardrobe is not integrated or redistributed.

Native marketplace escrow, disputed-task arbitration, abuse reporting, stronger anti-fraud measures, audited financial contracts, native-device testing and App Store/mainnet deployment require further implementation and validation.

The separate creator-economy specification describes future behavior. Creator payments, refundable XP commitments, follows and paid unlocks are not part of this deployed demonstration. Its current funding still uses two 50/50 buckets.

GitHub publication and hackathon submission have not been performed.
