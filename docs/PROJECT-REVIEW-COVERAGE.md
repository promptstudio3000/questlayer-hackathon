- 102 unique game rules; every rule maps to at least one tracker milestone.
- 15 milestones and 89 unique tracker tasks; no completedAt value and no full exit pass.

- The89 task rows preserve existing coarse tracker statuses. The rule/journey
  dispositions explain delivered slices and remaining gates; the tracker was not
